# Contributing to PGP Companion

Thank you for your interest in contributing to PGP Companion!  
This project is built on transparency, security, and community collaboration.  
All contributions are welcome — code, documentation, ideas, testing, or security reviews.

---

## 🧩 How to Contribute

### 1. Reporting Issues
If you find a bug or have a feature request:

- Open an Issue
- Describe the problem or idea clearly
- Include reproduction steps if possible
- Add logs or screenshots (avoid sensitive data)

Please do **not** report security vulnerabilities publicly.  
See `SECURITY.md` for responsible disclosure.

---

## 2. Pull Requests

### Steps:
1. Fork the repository  
2. Create a new branch  
3. Implement your changes  
4. Write clear, concise commit messages  
5. Open a Pull Request against `main`

### Requirements:
- Code must compile  
- No sensitive data in commits  
- No telemetry, tracking, or external analytics  
- No weakening of cryptographic components  
- Cryptographic changes must be documented and justified  

---

## 3. Coding Guidelines

- Kotlin, clean and modern  
- Keep dependencies minimal  
- Follow Zero‑Trust principles  
- No network calls without prior discussion  
- Private keys must **never** be stored unencrypted  
- Use memory wiping where applicable  

---

## 4. Documentation

Documentation contributions are highly appreciated:

- Improving the README  
- Adding examples  
- Writing tutorials  
- Architecture diagrams  
- Clarifying cryptographic flows  

---

## 5. Discussions

For larger changes:

- Open an Issue with the `proposal` label  
- Describe motivation, benefits, and potential risks  
- Discuss with maintainers and the community  

---

## ❤️ Thank You

Every contribution — big or small — helps make secure communication accessible to everyone.  
Thank you for being part of the project!
